===================================================================================================================================
METRIC DEFINITIONS
===================================================================================================================================
- Runtime Size   : Peak memory allocated in GB on the NVIDIA GB10 unified memory pool during execution.
- Fresh Prefill  : Prompt ingestion throughput (tokens/second) on a cold KV cache.
- Cached Prefill : Prompt ingestion throughput (tokens/second) with prefix KV cache reuse.
- Decode tps     : Generation speed (tokens/second) during streaming autoregressive token decode.
- Eff Gen tps    : Effective end-to-end generation throughput including Time-To-First-Token (TTFT) latency.
- Avg TTFT (s)   : Average Time To First Token latency in seconds.
- Gen Tok        : Total output tokens generated during the benchmark evaluation.
